Some markers for existing, roadmap or not planned features:

  1. Color GREEN - Existing feature, can be used immediately
  2. Color BLUE - Existing feature but needs adjustments/improvements to work with the requirments
  3. Color YELLOW - Function is already under work or planned for immediate future
  4. Color ORANGE - Function is on the roadmap, but work hasn't started on it, and is not planned to start in the next 2-3 months
  5. Color RED - Function is not part of the roadmap yet, there is no plan or even documentation for it right now

Customer Information Center (CIC)

Login system:

  • Software roadmap is aiming for unified login system ( same Login function for anyone logging in: Claimants, Agents, Claim handlers, Administrators, Supervisors, etc... )
  • Of course, the abilities of the person logged in will depend on the security settings and which organization they belong
    (or in case of claimants - automatic accounts not belonging to any "entity" yet - But they could be moved later into an actual customer organization, with an account upgrade)
  • This means, there is no separate "CIC Function, Claims Function, CIC Super Function" and so on... just different abilities of the software turned On/Off depending on account settings (via access rights)
  • We need more information about what those "Functions" actually are, to see if they fit into the application profile already, or need to be created in the future.

Note: While the application works just fine on a mobile ( as a webpage ), it's not very "small screen friendly" (hard to see the inputs).
Possibly solutions have been discussed but at the moment we don't have the necessary manpower to support two separate systems ( Website + Mobile App ), so I'm afraid a "Mobile App" cannot be implemented in the near future.

CIC Inquiries / Requirements:

  • This is actually a new data type (just like Claim, Incident, Quality Event, etc.). We can create more of these anytime (and doesn't take very long).
  • Obviouosly, the format of this data type needs to be understood and constructed
  • Filtering is already part of the system ( main grid, just switch to the new "Customer Inquiry" data type
  • Distribution or data records is possible by user assignment. Automatic assignment is already on the roadmap and will be implemented as soon as possible.
  • Activity log - Unfortunately we don't have this yet, even if it was discussed for quite a while. However, it is on the roadmap and will be implemented.
  • Communication is obviously part of the system from the begninng. A major upgrade to the communication system is near completion and will be deployed this month.
  • Statuses are already shown to the partner/beneficiary
  • User accounts can be controlled ( and disabled ). Since automatic assignment doesn't exist yet, this feature needs to be connected
  • We are already working on a configurable and flexible graphical dashboard, but right now it's in it's early stages. No estimate yet on when it will be completed

Customer Relationship Management (CRM)

  • While we have a free-access system, it was designed for submitting Cargo Claims, Incidents and other 1-way data transmissions. It's abilities for efficient 2-way interactions are very limited.
  • It would theoretically be possible to use normal "Accounts" to give access to various data types to your customers, but right now accounts cannot be created automatically. New functions for creation of accounts by the visitors themselves need to be developed.
  • We have E-mail sending abilitites right from the beginning, but we do not have SMS abilities. Those will have to be negociated with a 3rd party and integrated in the system.
  • The software's purpose is not designed for marketing/mass mailing. Some other tool need to be used for that. We will provide however a method of extracting customer e-mails from the system.
  • Live chat is part of the roadmap without being a priority
  • Same login system for everyone. Only abilities differ. VIP customers will have their own "organizations" in the system, set as "partner" to yours (Saudia Cargo), so you are able to communicate and share data with them
  • "Setup a process to track all CRM activities" - This requirement is not clear. What do you mean?
  • "CRM Supervisor screen" - We already have the data grid which has the ability to locate information very easily. Is this what you mean ?
  • "Loyalty Program option" - Please explain this requirement
  • "Ability to generate detailed and highly targeted e-mailshots" - What exactly is this ?
  • Cannot answer to any question related to "Integration" with another software until we have detailed information about what that software does and how it works. It might even not be possible to connect to other software if it is closed-source and cannot be modified (or no longer supported by it's original vendor)
