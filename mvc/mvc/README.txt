This is a custom mini-framework on which the Cargo ITS Application runs.

It has no special name, the primary class is named "MVC_Core"

While MVC prefix would suggest a Model-View-Controller architecture, it is actually closer to a Model-View-Presenter architecture,
in which the presenter combines data from the model with a set of templates (views), which is then sent to the browser.
