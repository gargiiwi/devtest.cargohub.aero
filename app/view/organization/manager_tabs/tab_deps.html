Currently this organization doesn't have any departments.

Please use the [ Add new ] button to create a department, then you will be able to add and manage it's members, configure department level access and other department related operations.

Without departments, all users are considered equal and they inherit the organization-wide access rights. Individual rights cannot be configured. In order to organize access for users at least one department must be created, and any users added to it can either inherit department-level access or be configured individually.

Important note: If the organization doesn't have any users yet, you will not be able to create a department, as the create procedure asks for one user to become the initial Chief of this department. Make sure the organization has at least one user before creating a department !
