 {!Right side}

New record department links:

When an user creates a record or the department receives it externally, this controls which other deparments get access to the record of mentioned type.

This takes effect only on initial submit or receipt, any other changes to Access Control are not affected by these settings.
Note: The linking is per record type, so each record type has it's own list of also-linked departments!
