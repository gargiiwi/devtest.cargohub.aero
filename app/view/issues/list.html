The List and Search section shows available records of one Record Type.

You can use this section to find data and perform certain operations on one or more records.
This grid is customizable, it is possible to choose which record fields are being shown, in what order and define your own widths for any column

Stored Views and layout management

Once the grid has been configured to your liking, the layout can be saved into Views by using the command Save view as... from the Views menu.
You will be able to retrieve and reuse the same view anytime.

Views store both the columns and the current filters/grouping/sorting, so you can come back anytime to your exact preferred display of information

Exporting data to Excel, HTML and CSV

The software will attempt to export the exact information you see on the screen in one of the available formats:
MS Excel (XLSX), HTML (For direct printing) or CSV (For importing into other software)
Please note that it's possible the export will not be perfect, depending on certain columns.

Use the Views function to define your export formats, then switch to a view, set your desired page size (only current page is exported) and use the Export table function in the menu
