Operational information (click to open)

This is the global user search system.

All users from all organizations are listed here, allowing the administrator to quickly locate users by their e-mail addresses, names or other characteristics.
The search system is server-side filtered and sorted, so if the server load is high please be patient after typing something in the filter bar until the grid reloads

When selecting a row, it is possible to view details about that user, view the organization he or she belongs to and also remove the user

Please BE CAREFUL with the delete function, it's not reversible ! Once an user has been deleted, his/her data cannot be recovered

In order to create an user, you must go to the organization module and create it from there. It's not possible to add an user directly from here
