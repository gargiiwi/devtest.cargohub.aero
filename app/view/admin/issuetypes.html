The columns display the following information:

  • Scope: Usage class for this issue type (everyone, only an organization, admin build/test mode)
  • Folder Key: Shows the Issue Type Key (Template folder name).
  • Name: Singular name used in the application.
  • Plural form: Name used when multiple issues are mentioned (Plural).
  • Description: What this issue type is about.
  • Issues: How many issues of this type are recorded in the application (total, including hidden, closed).

When selecting a row, buttons will appear that allow to view details about that issue type or remove it (after confirming twice)

Please DO NOT USE the delete function, it's not reversible !
Once an issue type is removed, ALL DATA OF THAT TYPE CANNOT BE RECOVERED.

To create an issue type, use the provided button which opens the issue type create form.
Each issue type must have an unique folder key (the system will refuse creation if the same name has already been used).
