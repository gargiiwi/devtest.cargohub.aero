Operational information (click to open/close)

This is the organizations manager.

All organizations which use (or might use) the system are displayed here.
For now, all information is loaded at the start of this module so filtering and sorting is done locally in your browser (will be changed when there are more than 1000 organizations in system)

The columns display the following information:

  • Active: This organization is set as active and it should have users operating issues. If inactive, issues can only be submitted by e-mail.
  • Type: What kind of organization it is (Airline, Claim Agent, Sales Agent, Shipper, Trucker, etc.)
  • Primary URL: This is the main portal address for this organization, where issues can be submitted. (There can be other addresses with different purposes)
  • Managed by: The user which is set as the manager of this organization.
  • Users: Number of user accounts connected to this organization.
  • Issues: Issues associated with this organizations.
  • Msgs: Messages to and from this organization. A high number usually indicates a very active organization.
  • Files: Files uploaded for this organization. A high number indicates large server space usage.
  • Dept's: Number of departments in this organization. More than one indicates this is a wide-area corporation.
  • Domains: Internet addresses which direct to this organization. In most cases each organization has only one domain.
  • Groups: Number of groups connected to the organization. Groups are of multiple types and managed in the groups module.

When selecting a row, buttons will appear that allow to view details about that organization or remove it (after confirming twice)

Please BE CAREFUL with the delete function, it's not reversible ! Once an organizaiton has been deleted, data cannot be recovered.
It is possible however to lock the delete function for organizations by directly editing the database (not from the interface). This can avoid accidental deletions

To create an organization, use the provided button, in which a name, type and first internet domain name must be specified. After the organization is created, it can be further configured by using View and edit button.
Each organization must have an unique name (the system will refuse creation if the same name has already been used), and the primary domain must not exist in the system yet.
