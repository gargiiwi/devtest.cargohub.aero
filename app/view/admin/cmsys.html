Content Page Editor

Click on a file on the left side tree to load it.

This introduction will be replaced by the content of the file and become the editor you can use to change the content of that file.

It's also possible to create a new file by pressing the [Create Page] button in the toolbar above.

Before clicking on a page, choose which editor will be used for displaying the page with the Options button. The available options are:

  • CodeMirror (Programmer Editor) - Supports HTML+CSS code, better for templates and non-standard HTML.
    Displays line numbers and keeps the code as it was.
  • TinyMCE (Visual Editor) - Allows editing content in a friendly manner but it can change the underlying code unpredictibly.

    Be warned, when a document has been transformed by TinyMCE IT CANNOT BE REVERSED.
    Use with extreme caution, and avoid if possible !
    In general, only edit documents which were created by TinyMCE itself.

    Make backups using CodeMirror before attempting any change

Note: Choosing another editor will reload this module.

Have fun ;)
