Currently online users.

All users that are currently online (logged in and performed operations in the last two hours) are listed here, allowing the administrator to check on the system activity.
The search system is server-side filtered and sorted, so if the server load is high please be patient after typing something in the filter bar until the grid reloads

When selecting a row, it is possible to view details about that user, login as that user or disconnect the user (forcibly log-out)
