The organization selector refers to contacts created by that organization's users, and has nothing to do with contacts for records submitted or shared to that organization


How to use the Global Contacts Management module (click to open/close)

This module allows searching and editing any registered contact records (Except for users, those have to be edited from the User Management interface).

The list of Types:

  • system - This contact is internal to the software and should cannot be altered from this editor
  • global - "Yellow pages" type contact, visible to all users
  • organization - Organization wide contacts, visible by all users of a specific organization
  • org_self - Represents the name and details of system organization accounts

Note: Currently it's not possible to change the contact type
