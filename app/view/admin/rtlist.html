Record Types Overview

The columns display the following information:

  • Scope: Usage class for this record type (everyone, only an organization, admin build/test mode)
  • Name: Singular name used in the application.
  • Recs: How many records of this type are stored in the database (total, including hidden, closed).
  • Folder Key: Shows the base directory name for the template files
  • Plural form: Name used when multiple issues are mentioned (Plural)
  • Description: What is this record type about

When selecting a row, buttons will appear that allow to view and edit details about that record type

Note: The "Archive" button doesn't remove information, it simply changes the scope to "arhive"e;, making the Record Type invisible for normal users
Archived records get moved to the end of the grid, but can still be searched and changed. This can be used to hide a RT temporarely for maintenance

To create a new record type, certain information needs to be entered before the necessary file structure is created and editing is allowed

Each issue type must have an unique folder key (the system will refuse creation if the same name has already been used).
