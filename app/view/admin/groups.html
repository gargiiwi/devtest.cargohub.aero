Data Groups Editor

Please select a group type from the menu to see available groups in a grid.
The other menu options related to a specific group type will also appear when the group is selected

What are "Groups" ?

A group is a collection of related issue records.
It is used to determine visibility/access of organizations to a certain information and can be used in the security system.

Different types of groups provide custom functionality, so it is necessary to choose a type.
The system currently supports these group types:

  • General Category - For various other issue types. It's possible to select only certain groups when defining an issue type.
  • Airline/Carrier - Used primarily for Air Cargo Claims but also for Truck orders, Airport/Airline Cargo Incidents and others.
  • Shipping line/Agent - Used for Oceam Cargo Claims, these are used to sort organizations involved in Ocean/Marine trade.
  • Name of department - Used by some modules which distribute their data over organization departments
  • License type - Used by the License monitor
  • Primary Customer - Currently used only by Road Cargo Claims.
  • Platform area - Used in the Development items and Support tickets. It's possible to select only certain groups when defining the record type.
  • Class of item - Used for the Dangerous Goods module. It's possible to select only certain groups when defining the record type.
  • Training - Used for the Training module.
  • Asset - Currenly only used for Road Cargo Claims
