Operational information (click to open)

An Airline group represents the "name" of an air transportation service, and not the company itself. When choosing the Airline (or Carrier) on submitting an issue like Claim, Incident, Damage Report, the issue is placed in this group, and it doesn't mean that the company which has this name will receive the Claim. In order for the organization to access the issue, they must have an account in the system and must receive "ownership" of that issue. Only then they will be able to see and operate the issue.

Ownership is given in the following ways:

  • When submitting an issue from the public area, the setting "Master Handler" which is present in this grid is checked. The organization that is the Master Handler for a certain Airline Group will become the initial owner of the issue.
    The Master Handler does not need to be the Airline company itself, it could be an Agent, GSA or other companies involved.
    Only the organizations connected to this group can be chosen as the Master Handler, so in order to change this setting connect first the appropriate groups to an organization.
  • When submitting an issue by a user which is logged in as a staff member, the owner of the issue will always be the organization in which the user is.
  • Issue ownership can change with a special "Give To" function which organizations (will) have. (Feature which is planned to be implemented soon)

Some data in this grid is taken from a database with all the airlines in the world (AirWayBill Prefix, IATA and ICAO allocated codes, the Country where this Airline organization has it's headquarters and of course, the official Name). These informations cannot be changed here (and there's no need, as these are international allocations which very rarely change)

The last two columns are related to the Airline Search System but also the submit forms:

  • Redirect Domain: When this airline is chosen in the search system, clicking on the GO! button will redirect to this domain and present the submit form for the chosen issue type (or the implicit one)
    The domain names must be previously created in the Organization's Control Panel before they can be set here.
  • Submit On: If checked, this Airline group allows submitting from the Airline Search. If set to Off, submitting is denied.
