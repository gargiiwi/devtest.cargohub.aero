Operational information...

An Airline data entry represents the name of an airline, used by the Airline Search System

These entries may or may not be used as Data Groups, but in order to create a Data Group, an Airline record in this database must exist first

Redirect URL is not set here, but in the Data Groups, and depends on the organization which receives master access to this Airline data entry
Status also can't be edited here, but is just an indication if this name has been used or not, or if it's ready for the search system

Database ID is assigned automatically when creating an Airline name, and cannot be changed.
