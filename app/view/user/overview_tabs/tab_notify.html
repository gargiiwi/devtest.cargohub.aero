Information about the notifications grid (click to show/hide)

This is the list of notifications that you received.

CargoHub Connect records all the notifications that you have received, so nothing is forgotten. When you reaceive a notification about an event, it will be visible here in this grid.

You have the ability to read, dismiss or archive one or more notifications, and also search among them using the grid's search header.
A read or dismissed notification is not counted and shown in the notification bar, but is still visible in the grid. By default, the archived notifications are not shown and you have to actively enable them to view them.

Notifications cannot be directly deleted, however the system automatically cleans archived notifications which are older than one year.
